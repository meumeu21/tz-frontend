# Блок Progress

Блок представляет собой круговую шкалу, которую можно настроить по следующим состояниям:
1. Нормальное (изначальное) состояние - шкала изменяет свое значение от 0 до 100;
2. Анимированное состояние - шкала вращается по часовой стрелке;
3. Скрытое состояние - шкала скрыта с сохранением размера.

Вёрстка выполнена по методологии БЭМ.

Деплой: https://meumeu21.github.io/tz-frontend/

## Описание файлов

### index.html - разметка страницы
Панель с заголовком, контейнером .panel__progress для компонента
и блоком управления: числовое поле Value, переключатели Animate и Hide. 
Подключает progress.css, style.css и app.js.

### style.css - стили страницы
CSS-переменные, панель .panel, поле ввода .field и переключатели .toggle, 
собранные на чекбоксах. Содержит @media (orientation: landscape), 
меняющее размеры панели и раскладку страницы с вертикальной на горизонтальную.

### Папка progress (progress.css, progress.js) - компонент Progress
Стили и логика лежат в отдельной папке, не зависят от разметки и стилей 
страницы и подключаются вместе. Компонент сам создает свой DOM-элемент 
внутри переданного контейнера и управляет только им.

#### progress/progress.css
- .progress - блок шкалы. Круг рисуется через conic-gradient по переменной
  --progress-value (заполненность в процентах), середина вырезается через маску
  radial-gradient, ширина кольца задается переменной --progress-thickness;
- .progress_animated - модификатор анимации, запускает вращение
  по часовой стрелке через @keyframes progress-spin;
- .progress_hidden - модификатор скрытия, использует visibility: hidden,
  поэтому при пропадании шкала продолжает сохраняет место.

#### progress/progress.js
Класс Progress - логика компонента.

Статические поля:
- MIN_VALUE, MAX_VALUE - публичные значения диапазона шкалы (по умолчанию 0 и 100);
- #BLOCK, #ANIMATED, #HIDDEN - имена классов блока и модификаторов;
- #STYLE_VALUE - имя CSS-переменной --progress-value.

Методы:
1. constructor(root, { min, max, value, animated, hidden }) - проверяет
   аргументы (root - DOM-элемент, min и max - целые числа, min не
   отрицательный и меньше max), создает элемент .progress, добавляет его в root 
   и отрисовывает начальное состояние;
2. setValue(value) - устанавливает нормализованное значение шкалы по
   диапазону, перерисовывает блок;
3. getValue() - возвращает текущее значение шкалы;
4. setAnimated(animated) - включает/выключает анимацию вращения;
5. isAnimated() - возвращает true, если анимация включена;
6. setHidden(hidden) - скрывает/показывает шкалу с сохранением размера;
7. isHidden() - возвращает true, если шкала скрыта;
8. getPercent() - вычисляет заполненность шкалы в процентах от диапазона;
9. getMin() - возвращает нижнюю границу диапазона;
10. getMax() - возвращает верхнюю границу диапазона;
11. destroy() - удаляет элемент из DOM и ставит null компоненту;
12. #render() - приватный метод перерисовки: записывает процент в CSS-переменную
    и переключает модификаторы progress_animated и progress_hidden; бросает
    ошибку, если компонент уже уничтожен;
13. #normalize(value) - проверяет целость значения и
    ограничивает его диапазоном min-max.

### app.js
Класс App - контроллер приложения. Связывает элементы управления на странице
с компонентом Progress. На старте в window.app создается экземпляр для .panel.

Статические поля:
- #PROGRESS_SELECTOR, #VALUE_SELECTOR, #ANIMATE_SELECTOR, #HIDE_SELECTOR -
  селекторы по классу контейнера шкалы и элементов управления;
- #DIGITS - регулярное выражение, разрешающее вводить только цифры.

Методы:
1. constructor(root) - проверяет, что root DOM-элемент, находит по селекторам
   контейнер шкалы и элементы управления и проверяет их: контейнер должен быть
   DOM-элементом, поле ввода и переключатели - элементами input. После прохождения
   проверок создает компонент Progress в контейнере, задает атрибуты поля
   ввода, подписывается на события и синхронизирует элементы управления
   с состоянием компонента;
2. setValue(value) - устанавливает значение шкалы;
3. setAnimated(animated) - включает/выключает анимацию;
4. setHidden(hidden) - скрывает/показывает шкалу;
5. destroy() - отписывается от всех событий через AbortController и уничтожает
   компонент Progress;
6. #setValueInputAttributes() - проставляет полю ввода атрибуты min и max из диапазона компонента;
7. #bindEvents() - подписывается на события beforeinput и input поля ввода 
   и на change переключателей, передает signal от AbortController для отписки;
8. #onValueBeforeInput(event) - отменяет ввод и вставку всего, что не является цифрами;
9. #onValueInput() - передает нормализованное (для пустого/некорректного значения возвращает min) 
   значение поля в компонент и синхронизирует поле с нормализованным результатом;
10. #syncValueInput() - записывает в поле текущее значение компонента, если оно отличается от введенного;
11. #onAnimateChange() - обработчик переключателя Animate;
12. #onHideChange() - обработчик переключателя Hide;
13. #syncControls() - приводит поле ввода и оба переключателя в соответствие с состоянием компонента.
