# Блок Progress

Блок представляет собой круговую шкалу, которую можно настроить по следующим состояниям:
1. Нормальное (изначальное) состояние, при котором возможно изменять значение шкалы от 0 до 100;
2. Анимированное состояние, при котором шкала кружится вращается по часовой стрелке;
3. Скрытое состояние, при котором шкала не отображается.

Файлы:
1. index.html - разметка, названия классов соответствуют методологии БЭМ;
2. style.css - стили (соответственно, тоже используется БЭМ);
3. progress.js - API блока Progress;
4. app.js - контроллер приложения.

Особенности:
- Отображение значения на шкале реализовано через использование функции conic-gradient с основным цветом и белым и через after (без after получается круговая диаграмма);
- Введенное значение шкалы ограничивается диапозоном через функцию clamp;
- Анимация происходит через класс progress-bar-animated. Она линейна и повторяется постоянно;
- Кнопка отключения отображения шкалы добавляет на нее класс progress-bar-hidden со свойством display: none;
- Приложение адаптировано под ориентацию экрана через медиа-запрос, который меняет ширину приложения, направление оси флекс-контейнера и внешние отступы;
- Кнопки анимации и отключения отображения сделаны через стилизацию span, находящемся сразу под чекбоксом;
- Есть функции setValue, toggleAnimation, toggleVisibility, к которым можно обращаться из консоли веб-инспектора через window.app (например, window.app.setValue(50)).
